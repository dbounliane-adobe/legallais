# Breadcrumb

One cell holding a list of links (`Accueil > Univers > Catégorie`). The last item is the current page.
Add a univers variant (`breadcrumb (genie-climatique)`) to use the univers colour
(classes defined in `styles/styles.css`: batiment, agencement-ameublement, plomberie, genie-climatique,
electricite, consommables, outillage, materiels-et-equipements, epi).
